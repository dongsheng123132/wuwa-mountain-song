## E. 如何下载参考音频（仅供个人学习）

> **重要声明**：以下方法仅用于个人创作研究，不得二次传播或商用。
> 下载的音频不要打包进 GitHub 仓库。

### 工具：yt-dlp（开源命令行）

```bash
# 安装（Windows + 已配代理）
pip install yt-dlp

# 下载 YouTube 音频为 MP3
yt-dlp -x --audio-format mp3 \
  --proxy http://127.0.0.1:7897 \
  -o "%(title)s.%(ext)s" \
  "https://www.youtube.com/watch?v=XXXXX"

# 下载 B 站音频
yt-dlp -x --audio-format mp3 \
  "https://www.bilibili.com/video/BVXXXXX"
```

### 替代：在线转换工具
- y2mate.com（YouTube）
- bilibili-mp3.com（B站）
- 网易云音乐 PC 客户端（自带下载，需 VIP）

下载后建议放在工作目录之外的私人文件夹，例如 `C:\Users\ZhuanZ\Music\花瑶迎宾曲参考\`，**不要 commit 到 git**。
