# v2 · 抖音 15s 嗨爆版

> 一句话定位：**最强洗脑、最低跟跳门槛、最快完成动作记忆**。

## 元数据

| 字段 | 值 |
|---|---|
| 风格 | 纯电子 + chant + 大鼓 |
| BPM | 128（房舞 four-on-floor）|
| 调式 | F 徵五声 |
| 时长 | 18 秒（标准抖音切片）|
| 主乐器 | 808 kick / chant 人声采样 / 锣 / 唢呐 hook（一声）|
| 段落 | 4 拍 build → 8 拍 hook × 2 |
| 目标场景 | 抖音 / TikTok / 视频号挑战赛 |

## 创作目的

在 18 秒内完成 3 件事：
1. 听到「呜哇」声（**3 秒内**——刷视频划走窗口期）
2. 记住「迎客来」一句（**8 秒内**——超过这个时间记忆度暴跌）
3. 看到一个简单到能复刻的动作（**全程穿插**）

**不做**任何叙事。叙事让位给记忆点。

## 完整歌词（用于 Suno）

```
[Build-up 4 拍]
(electronic build-up, rising filter)
(锣 × 1)

[Drop / Hook 8 拍]
呜哇！呜哇！呜哇咧——
迎客来！迎客来！花瑶迎客来！

[Hook 重复 8 拍]
呜哇！呜哇！呜哇咧——
干一杯！干一杯！米酒满满杯！
```

完整歌词只有这些。**没了。**18 秒，全部就是 hook。

## 抖音剪辑指引（15-18 秒切片）

```
[0:00-0:03]  视觉：花瑶女孩转身露出银饰特写
            音频：build-up + 锣声
[0:03-0:11]  视觉：3 人/5 人/全场齐跳 8 拍迎宾舞
            音频：hook 第一段「呜哇！呜哇！呜哇咧——迎客来」
[0:11-0:18]  视觉：举酒杯 + 慢动作 + 字幕「干一杯」
            音频：hook 第二段「干一杯！干一杯！」
[0:18 终]    定格 + 字幕「#花瑶呜哇山歌挑战」
```

**配套挑战标签**：`#花瑶呜哇` `#迎客来挑战` `#呜哇dance`

## 配套舞蹈（极简 4 拍）

```
拍 1: 双手举酒杯（向前）
拍 2: 双手转一圈（向上）
拍 3: 单脚跺地（左/右交替）
拍 4: 拍胸（一下）
```

**关键约束**：
- ❌ 不要超过 4 拍
- ❌ 不要双人配合动作（一个人就能拍）
- ❌ 不要需要专业舞蹈基础
- ✅ 必须能在 1 米见方范围完成

## 失败止损线

发布 3 条测试视频，**24 小时内：**
- 单条 < 1 万播放 → 配乐有问题或视觉无吸引力
- 单条 < 100 跟拍 → 挑战舞太复杂，必须简化
- 完播率 < 30% → 18 秒太长，砍到 12 秒重剪

**90 天内单条无 50 万播放 → 这个版本归档**，不强推。

## 配合传播脚本

适合发什么样的视频：
- ✅ 真实节庆现场（讨僚皈、火塘边、梯田）
- ✅ 银饰/挑花裙特写慢动作 + 副歌爆点
- ✅ 多人合跳镜头切换（让算法识别为"挑战类"）
- ❌ 长篇花瑶文化讲解（v3 v5 干这个）
- ❌ 个人独白抒情（v4 干这个）

## 与原版的关系

v2 = 原版 v1 副歌的 **暴力浓缩**。
- 直接砍掉 Verse / Pre / Bridge
- BPM 从 92 提到 128（房舞标准）
- 加重底鼓和锣，去掉所有民乐复杂层
- 把唢呐从"melodic"角色降为"one-shot stab"

**v2 自己活不下去**——它依赖 v1 的完整版做"想了解更多请点头像看完整版"的引流。这是**钓饵**，不是**主菜**。
