# 歌词与编曲多版本 · Lyrics Variants

> **核心策略**：6 把刀同时出鞘，每把对准一个传播场景/人群。
> 任意一个版本破圈，就算项目跑通。

## 共享的"不变量"（所有版本都遵守）

- ✅ 副歌核心 hook **永不可变**：「呜哇！呜哇！呜哇咧——迎客来！」
- ✅ 主旋律调式：F 徵调式五声音阶（pentatonic on F）
- ✅ 文化标记衬词：「呜哇」「咧」「哎呀嘞」（来自呜哇山歌千年传统）
- ✅ 不冒充花瑶语：除已有衬词外，不编造花瑶语台词
- ✅ 不直接采样具体音频/旋律（保持 CC BY-SA 4.0 干净）
- ✅ 主题：迎宾、敬酒、花瑶文化、虎形山

## 选用决策树

```
你想推广给谁？
├── 抖音年轻人 / TikTok          → v2 抖音版（剪 15s 切片）
├── 政府机构 / 央视 / 非遗圈     → v3 纯民族版（递交官方）
├── 朋友圈中年人 / 视频号        → v4 抒情版（家乡情绪带）
├── B站民乐区 / 小红书故事感     → v5 对唱版（长版叙事）
├── 海外 / Spotify / YouTube     → v6 世界版（中英双语）
└── 不确定 / 全年龄通用          → v1 原版（已发布）
```

## 各版本如何被使用

### 阶段 A：内容池准备（D1-D30）
全部 6 个版本**先在 GitHub 挂着**，给协作者预览。

### 阶段 B：A/B 数据测试（D31-D60）
用 v2 v4 v6 三个最锋利的版本，分别投 3-5 个素人测试号，看 24h 数据。

### 阶段 C：节庆引爆（D61-D75 讨僚皈节）
**所有版本同时出现在节庆现场**——不同协作者用不同版本，覆盖最大可能性。

### 阶段 D：复盘聚焦（D76-D90）
数据最好的 1-2 个版本 → 加大投入做真人版 → 其他版本归档。

## 给协作者的提醒

⚠ **不要"挑一个最好的"——这是 AI 时代爆款的反直觉规则**：

- 单点爆款已死。今天爆款的来源是"多版本同时投放，由数据选出冠军"。
- 你以为最好的版本，未必是用户喜欢的版本。
- **先广撒网，再聚焦**——这才是数据驱动的传播路径。
