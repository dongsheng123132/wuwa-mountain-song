# v6 · 跨语言世界版

> 一句话定位：**Spotify / YouTube 上让外国人单曲循环的版本**。

## 元数据

| 字段 | 值 |
|---|---|
| 风格 | World Music + Tribal Welcome Anthem（对标 Jerusalema）|
| BPM | 100 |
| 调式 | F 徵五声 + 国际化和声 |
| 时长 | 3:20 |
| 主乐器 | Tribal drum / Suona / Synth pad / Bass / Mixed choir |
| 段落 | Intro → Verse → Hook（中文+英文）→ Verse → Hook → Bridge → Final Hook |
| 目标场景 | YouTube / Spotify / Apple Music / 海外华人 / 民族风国际听众 |

## 创作目的

回答一个问题：**怎么让一个不懂中文的尼日利亚大叔愿意听完？**

v6 必须做到：
- 副歌**有英文短句**（让国际听众有抓手）
- 但**英文不抢戏**——「呜哇」依然是核心标识
- 编曲**借鉴 Jerusalema** 的 4-on-floor + tribal drums
- **简单到非中文母语者也能哼**

## 英文歌词的设计原则

| 原则 | 解释 |
|---|---|
| **英文必须辅佐"呜哇"，不能盖过** | 「Wu-wa」是核心标识，英文是脚手架 |
| **英文用最简单的小学词** | welcome / home / friend / drink / mountain / cup / moon |
| **押 home/cup/moon 这种闭口元音** | 国际听众跟唱时不会"吞字" |
| **不翻译"呜哇"** | 保留原汁，让外国人也喊"Wu-wa" |
| **不翻译"花瑶"** | 翻成 Hua Yao（拼音）即可，建立品牌 |

## 适合什么样的视频/场景

✅ **完美匹配**：
- YouTube World Music 频道
- Spotify "Global Sounds" / "World Folk" 歌单
- TikTok 海外（不是抖音国内）—— `#WorldMusic` `#ChineseFolk`
- 海外华人春节/中秋庆祝活动
- 国际文化交流会议背景音
- 联合国教科文组织（UNESCO）非遗推广

❌ **不适合**：
- 抖音国内（中英混合不如纯中文洗脑）
- 央视严肃节目（中英混合不够"庄重"）
- 视频号（中年观众不接受英文）

## 失败止损线

- YouTube 单视频 > 10 万播放 → 启动
- Spotify 月听众 > 1 万 → 成功
- 任何海外 KOL（>10w 粉）使用 → 现象级
- 6 个月内国际平台 < 1 万播放 → 国际化方向走错，归档

## 与其他版本的关系

- v6 = **Jerusalema 路径的中国答卷**——能不能跑通看 v6
- v6 是 v2 的国际版镜像——v2 抖音国内，v6 TikTok 国外
- v6 不是给国内观众的——别在抖音/视频号投 v6，浪费弹药
- v6 的成功**反哺 v1 v2 v3 v4 v5**——海外火 → 国内更愿意接受

## 制作真人版的注意事项

- 中文段：建议**带湖南口音**的演唱，更"地道"
- 英文段：**不要标准美式英语**——稍带中国口音反而真实
- ❌ 不要找北美华裔英语母语者——会失去"民族风"质感
- ✅ 找在中国生活多年的外国朋友合唱英文段最理想
- 唢呐 + bass 的低频对位是 Jerusalema 公式核心，**混音重点**

## 文化合规

英文歌词中提到的元素：
- ✅ "Mountain of flowers"（花瑶 = mountain of flowers，文化对应翻译）
- ✅ "Silver bells"（银饰，物理对应）
- ✅ "Grandmothers sing"（祖辈传承，普世概念）
- ❌ 不出现 "exotic" "mystic" "ancient wisdom" 这种 **东方主义陷阱词**
- ❌ 不出现 "secret" "hidden" 这种神秘化词汇
