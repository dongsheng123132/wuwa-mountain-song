# v4 · 抒情家国情怀版

> 一句话定位：**让 70-90 后边开车边掉眼泪的版本**。

## 元数据

| 字段 | 值 |
|---|---|
| 风格 | 半 Ballad / 国民抒情 / "早安隆回"气质 |
| BPM | 72（钢琴抒情速度）|
| 调式 | F 徵五声（保持），但和声向 Pop Ballad 靠拢 |
| 时长 | 3:30 |
| 主乐器 | 钢琴 / 弦乐组 / 唢呐 solo / 轻底鼓 |
| 段落 | Intro钢琴 → Verse → Pre → Hook → Bridge → Hook 升 key → Outro |
| 目标场景 | 视频号 / 快手 / KTV / 朋友圈背景音 |

## 创作目的

回答一个问题：**怎么让一个 50 岁的湖南人，听完后转发给老家亲戚？**

v4 必须做到：
- **歌词**有家乡叙事（虎形山、火塘、母亲、归乡）
- **副歌**保留「呜哇·迎客来」hook，但**情绪**从"派对"变成"想家"
- **编曲**主体钢琴 + 弦乐，唢呐**只在副歌爆发**当作"乡音"出现
- **末段升 key**——这是中国 Ballad 的"必杀技"

## 编曲细节

| 段落 | 主乐器 | 情绪 |
|---|---|---|
| Intro | 钢琴 + 远山呼号 reverb | 静、空、远 |
| Verse 1 | 钢琴+弦乐pad | 独白、内省 |
| Pre | 弦乐渐强 + 唢呐入 | 期待、推进 |
| Hook | 全员（弦+鼓+唢呐+合唱）| 释放、抒情 |
| Verse 2 | 钢琴+弦乐 | 女性视角、柔 |
| Bridge | 钢琴退、弦乐独白 | 升华、家国 |
| Final Hook | **升 key** + 全员爆 | 高潮、流泪 |
| Outro | 钢琴尾奏 | 余韵、收 |

## 适合什么样的视频/场景

✅ **完美匹配**：
- 视频号 / 快手"老家"主题视频
- "我的家乡"系列短片背景音
- KTV 中老年点歌曲库
- 春节归乡片段配乐
- 退休群体合唱团表演
- 文旅短片《我的湖南》系列
- 朋友圈"想家"配乐

❌ **不适合**：
- 抖音 15 秒切片（情绪需要至少 1 分钟铺垫）
- 派对、婚礼热场
- 国际化场合（v6 干这个）

## 失败止损线

- 视频号转发量 > 1 万 → 启动
- 快手家乡话题 > 100 万播放 → 成功
- 凤凰传奇 / 袁树雄团队 1 次提及 → 现象级
- 90 天无任何上述指标 → 抒情方向走错，归档

## 与其他版本的关系

- v4 = **情绪炸弹**，瞄准的是"思乡"这个永恒赛道
- v4 是**老人脑海里能记住的版本**——v2 v6 太"年轻"
- v4 蹭《早安隆回》余热，但**不是抄袭**：调式、副歌、文化背景全部不同
- v4 是 v2 之外的另一条传播主线，**两者并行投放**

## 制作真人版的注意事项

如果用真人录唱：
- 男声 Verse 1：建议湖南本地 50+ 岁有沧桑感的演唱者
- 女声 Verse 2：建议湖南本地 40+ 岁柔情型嗓音
- **不要**找标准流行唱法的年轻歌手——质感会立刻"跑偏"
- 唢呐 solo 必须找**民乐专业演奏者**——AI 唢呐细节会暴露
