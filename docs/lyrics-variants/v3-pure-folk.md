# v3 · 纯民族原生版

> 一句话定位：**没有一个电子音符，能上央视的版本**。

## 元数据

| 字段 | 值 |
|---|---|
| 风格 | 唢呐 + 长鼓 + 锣 + 男女混声 |
| BPM | 78（自然呼吸节奏）|
| 调式 | F 徵五声 |
| 时长 | 2:30 |
| 主乐器 | 唢呐 / 长鼓 / 大锣 / 木叶 / 竹笛 |
| 段落 | Intro → Verse 1 → Hook → Verse 2 → Hook → Outro |
| 目标场景 | 央视《非遗里的中国》/ 地方文旅频道 / 政府推广片 / 学术汇报 |

## 创作目的

回答一个问题：**如果央视来要素材，给得出手吗？**

v3 必须做到：
- 任何一秒**没有电子合成器声**
- 任何一句**没有英文衬词**
- 任何一段**有传统乐器细节**（不是 808 kick 配唢呐）
- 文化纯度可以**直接放在政府宣传片**

## 编曲细节

| 段落 | 乐器层次 | 演唱方式 |
|---|---|---|
| Intro | 单唢呐 + 远山回声 reverb | 单声部呼号 |
| Verse 1 | 唢呐持续低音 + 偶尔木叶点缀 | 男声叙事，自由速度 |
| Pre | 长鼓 + 大锣进入节拍 | 齐声朗诵感 |
| Hook | 全员（唢呐+鼓+锣+竹笛+木叶）| 男女混声合唱 |
| Verse 2 | 锣鼓退到背景 + 唢呐+笛 | 女声高腔领唱 |
| Hook | 全员渐强 | 男女轮唱 |
| Outro | 唢呐独奏 + 长 reverb | acapella 收 |

## 适合什么样的视频/场景

✅ **完美匹配**：
- 央视《非遗里的中国》节目素材
- 地方文旅局形象宣传片背景音
- 隆回县政府对外推介片
- 学术会议「花瑶非遗保护」专题片
- 博物馆展陈背景音
- 高规格官方礼宾迎接（虎形山乡迎接外宾）

❌ **不适合**：
- 抖音切片（节奏太慢，刷到会划走）
- 健身房 BGM（vibe 完全错）
- 婚礼酒店宴席（背景太"严肃"）

## 失败止损线

v3 不靠"播放量"评判——靠**官方采纳**评判：

- 6 个月内有 **1 个**地方电视台、文旅频道、政府账号采用 → 成功
- 12 个月内**任何**国家级媒体采访 → 现象级
- 12 个月内**零**官方机构理睬 → 文化纯度方向走错了，复盘改
