# 《呜哇·迎客来》主旋律简谱

## 基本参数

- **调式**：F 徵调式（民族五声音阶 1-2-3-5-6，主音 sol）
- **调号**：1 = F（如歌手嗓音偏低可降为 1 = D）
- **拍号**：4/4
- **速度**：BPM 92（中速偏快，符合迎宾欢快感，也方便跟舞）
- **音域**：低音 5（sol）—— 高音 3（mi）（约一个半八度，副歌严格控制在一个八度内便于跟唱）

## 关键设计说明

### 1. 为什么选 F 徵调式
- 徵调式（sol-la-do-re-mi）是湖南民歌、花瑶呜哇山歌最常用的调式之一
- 主音 sol 适合高腔起唱，与「呜哇」长甩腔天然契合
- F 调对普通人嗓音友好，男声不费力，女声不刺耳

### 2. 为什么副歌音域控制一个八度内
- 抖音爆款规律：副歌音域跨度小 → 跟唱门槛低 → 病毒式传播
- 花瑶呜哇山歌的高音留给 Bridge 段集中爆发（参考《青藏高原》结构）

### 3. 节奏设计
- BPM 92 = 行走节奏的 1.5 倍，迎宾时人能自然踏步跟随
- 副歌「呜哇！呜哇！呜哇咧！」三连击对应 3 个强拍，方便鼓掌、跺脚、举杯
- 电子底鼓 four-on-floor 公式（参考 Jerusalema），让传统民歌有"现代舞曲"的脚感

### 4. 真假声转换
- Verse 用真声（亲切叙事）
- Hook 用混声（合唱可参与）
- Bridge 翻假声高八度（花瑶高腔的招牌"穿透云天"）
- 这套结构同时致敬《青藏高原》和苗族飞歌的"起腔→正腔"张力

## MIDI 导出建议

如用 MuseScore 打谱，建议：
1. 主旋律轨：唢呐音色（GM #110 Bagpipe 或 SoundFont 中的 Suona）
2. 和声轨：男声 Aah / 女声 Ooh 双轨
3. 鼓轨：大鼓 + 锣（中国打击乐）+ 电子 Kick
4. 导出 MusicXML → 转 MIDI → 用 DAW 加电子鼓和混音

后续会在 `score/melody.musicxml` 提供可编辑乐谱（需要时再生成）。
