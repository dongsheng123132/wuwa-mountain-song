# 《花瑶花开》创作路径

这首歌采用“已审核角色图 + 少量图生视频 + 本地剪辑”的方式制作音乐视觉样片。

1. 保留阿瑶、阿风两张已校正的全身角色图，固定人物面容、花帽和服装。
2. 用阿瑶轻挥手、阿风邀请手势生成各 5 秒的动态镜头。
3. 以歌曲前 30 秒为样片区间，根据约 123 BPM 的节拍和段落切换镜头。
4. 使用静态图的轻微推近、服饰细节裁切和动态镜头交替，保留原歌曲为唯一声轨。
5. 导出 720×1280、30fps 的竖屏 MP4。

此次成功生成两段动态镜头，总时长 10 秒；生成费用按当时模型价格估算约 2 元。详见 `生成费用记录.json`。

## 30 秒样片镜头顺序

- 00:00–00:09.938：阿瑶全身、阿瑶挥手、片名出现。
- 00:09.938–00:19.783：阿风邀请手势、阿瑶挑花服饰细节、阿风近景。
- 00:19.783–00:30.000：阿瑶与阿风交替，阿瑶挥手收束，片名落版。

完整可编辑工程在 `06-制作工程备份/动态版工程`。
