# Suno AI 生成提示词（直接复制粘贴使用）

## 使用步骤

1. 打开 [https://suno.com](https://suno.com)
2. 登录账号（需付费 Pro / Premier 版本可生成完整长度，免费版每次约 2 分钟）
3. 点击 **Create** → **Custom Mode**（自定义模式）
4. **Style of Music** 输入下方"风格提示词"
5. **Lyrics** 粘贴下方"完整歌词"
6. **Title** 输入：`呜哇·迎客来 (Welcome of Hua Yao)`
7. 点击 **Create**
8. 生成约 30-60 秒，得到 2 个版本，选好的下载 MP3
9. 把 MP3 保存到 `audio/demo-v1.mp3`

## 三、生成技巧

### 如果生成的"民族味"不够浓
- 在风格里加 `traditional Chinese pentatonic`、`erhu`、`bamboo flute`
- 减少 `electronic` 的比重
- 加 `Yunnan style`、`Hunan style`、`mountain folk`

### 如果"洗脑感"不够强
- 在风格里加 `viral TikTok`、`earworm chorus`、`anthem`、`group chant`
- 强调 `chorus repeating wuwa wuwa wuwa`

### 如果想要男女对唱版
- 在风格里明确写：`male verse 1, female verse 2, mixed choir on chorus`

### 如果想要纯女声版（更适合迎宾感）
- 风格写：`solo female vocal with female choir, no male voice`

### 如果生成的太"嗨"，想要悠远感
- 加 `mountain ambience`, `wind sounds`, `distant echo`, `reverb-heavy`
- BPM 改为 80-85

## 四、生成后处理建议

1. **下载两个版本**：Suno 会生成两个变体，建议都下载比较
2. **重命名**：`demo-v1-suno-take1.mp3` 和 `demo-v1-suno-take2.mp3`
3. **试听检查**：
   - [ ] 副歌「呜哇」是否清晰可辨
   - [ ] BPM 是否在 90 左右
   - [ ] 整体氛围是否符合"迎宾欢快"
4. **如不满意**：调整风格关键词重新生成（Suno 每次结果不同）
5. **想要完整 3 分钟版**：用 Extend 功能延长，或拼接两次生成的结果

## 五、备选 AI 工具

如果 Suno 不可用，可以试：

| 工具 | 链接 | 特点 |
|---|---|---|
| **Udio** | https://udio.com | 与 Suno 类似，结构控制更细 |
| **天工 SkyMusic** | https://tiangong.cn | 国产，中文识别更准 |
| **Mureka** | https://mureka.ai | 国产，民族风识别较好 |
| **Stable Audio** | https://stableaudio.com | Stability AI 出品，更适合纯音乐 |

**推荐组合**：
- 中文民族风 demo → 天工 SkyMusic 或 Mureka（中文理解更好）
- 国际化 demo → Suno 或 Udio（音质更好）
- 都试一遍，挑最好的
