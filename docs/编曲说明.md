# 《呜哇·迎客来》编曲说明

## 一、整体定位

**「民族高腔 × 现代舞曲」双轨编曲**

- 上半身：花瑶呜哇山歌的灵魂（唢呐、大鼓、铜锣、真假声合唱）
- 下半身：全球爆款舞曲的脚（four-on-floor 底鼓、合成器低音、电子 hi-hat）

参考混合范式：A Tribe Called Red 的 "Powwow Step"（北美原住民传统鼓 × Trap 节拍）。

| 乐器 | 角色 | 出现段落 |

| **竹笛 / 葫芦丝** | 高音点缀，山林氛围 | Verse 间奏、Outro |

### 现代电子层

| 元素 | 角色 | 出现段落 |
|---|---|---|
| **Kick (electronic)** | Four-on-floor 舞曲底，BPM 92 | Hook 起、Final Hook |
| **Sub Bass (合成低音)** | 低频填充 | Hook 起 |
| **Hi-Hat (8th note)** | 节奏密度 | Pre-Chorus 起 |
| **Pad / Choir Synth** | 氛围铺底 | Bridge |
| **Reverse Cymbal** | 段落进入 | 每个 Hook 之前 1 拍 |
| **Vocal Chop** | 抖音切片版强化记忆点 | 切片版 |

### 人声层

| 声部 | 角色 | 出现段落 |
|---|---|---|
| 主唱（男）| Verse 1, Bridge | 真声叙事 |
| 主唱（女）| Verse 2 | 真声叙事 |

| Ad-lib（即兴呼号）| 全程 | 「呜哇！」「咧！」「哎！」 |

## 四、段落分镜（Arrangement Map）

```
[0:00-0:20] Intro      唢呐独奏 + 远山回声(reverb)
                        渐入风声 / 鸟鸣 sample
                        最后一声呼号「呜——哇——」

[0:20-0:50] Verse 1    男声 + 三弦 + 轻鼓
                        留白多,亲切叙事
                        女声合声 ad-lib

[0:50-1:05] Pre-Chorus 大鼓渐进、电子 hi-hat 介入
                        合唱铺垫「举起酒,抬起头」

[1:05-1:35] Hook ★     全编制!唢呐 + 大鼓 + 锣 + 电子底鼓
                        合唱「呜哇!呜哇!呜哇咧!」
                        ★ 抖音切片就用这一段 ★

[1:35-1:55] Verse 2    女声 + 月琴 + 葫芦丝点缀
                        转柔,与 Verse 1 形成男女对比

[1:55-2:10] Pre-Chorus 同前

[2:10-2:25] Hook       同前

[2:25-2:55] Bridge     真声铺垫(8 小节)
                        ★ 假声翻高八度爆发(8 小节) ★
                        所有乐器渐弱,只剩主唱+pad
                        最后一拍齐声呼号回到 Hook

[2:55-3:00] Final Hook 全编制 ×2,加万人合唱采样
                        最后一句 a cappella:「呜哇——迎客来——」

[3:00-3:10] Outro      唢呐独奏拖音 + 远山回声
                        渐弱至无声
```

## 五、混音重点

1. **唢呐**要"亮"但不刺耳：高频 2-4kHz 适度提升 2-3dB，加 plate reverb 中等
2. **大鼓**要"实"：60-100Hz 是核心，加 saturation 让它在手机外放也能听到震动
3. **铜锣**要"远"：长 reverb tail（2-3 秒），左右 stereo 拉开
4. **电子底鼓**和大鼓要错频：大鼓占 60Hz，电子 kick 占 80-100Hz，互不打架
5. **副歌合唱**要"宽"：双 take + chorus + 立体声扩展
6. **「呜哇」三连击**要"穿"：每个「呜哇」之间留 0.2 秒 silence 制造顿挫感
7. **万人合唱采样**要"远"：用 hall reverb，模拟体育场效果
8. **结尾 a cappella**要"近"：直接干声，与前面满编制形成强烈对比

## 六、抖音 15 秒切片专属处理

切片版（0:00-0:15）= [Hook] 第一段 8 小节，但要做**加速强化版**：

1. BPM 提到 95（更紧凑）
2. 第 1 秒就要听到「呜哇」记忆点（不要等 intro）
3. 加重 808 底鼓，让手机外放更"震"
4. 最后 1 秒留白 + 唢呐一声短呼号，方便循环播放
5. 视频建议：花瑶姑娘举酒杯定格 → 接舞蹈动作

## 八、若用 MuseScore 离线制作（路线 B）

1. 用 MuseScore 4（免费）打开 `score/melody.musicxml`
2. 配器映射：
   - 主旋律 → Suona / Bagpipe（GM #110）
   - 和声 → Choir Aahs（GM #52）
   - 鼓 → Taiko Drum + Tam-tam
   - 电子鼓需要导出 MIDI 后在 DAW（Reaper/Ableton/FL Studio）中加
3. 导出 → MP3 / WAV
4. 上 DAW 加电子层 + 母带处理
