## 画面安排(短片内部时间,非原曲时间码)

| 短片时间 | 画面 |
|---|---|
| 0–3 秒 | 阿瑶笑脸 + 完整大圆花帽,一开场就唱“花瑶花瑶,花开隆回”。不要片名,不要长航拍。 |
| 3–9 秒 | 全身/中景：绿色花袖、黑色背心、彩色腰带、裙装,轻轻转身、向镜头招手。 |
| 9–15 秒 | 阿风回应,男女同框,动作简单如邀客,不演复杂爱情剧情。 |
| 15–24 秒 | “摇啊摇啊、唱啊唱啊”配小组欢舞,穿插裙摆、脚步、笑脸。群演服装沿用本地参考。 |
| 24–30 秒 | 回到阿瑶或男女同框 + 村寨欢聚;结尾叠字“花瑶花开,隆回等你来”,音乐收在完整乐句。 |

## 素材策略(低成本)

| 素材 | 做法 |
|---|---|
| 阿瑶笑脸、花帽、阿风、挑花细节、村寨 | 沿用已审图片,轻推拉 + 卡点切换 |
| 阿瑶招手、彩带随风、小幅转身 | 图生视频 3 段 × 5 秒(`wan2.6-i2v-flash` 720P 无声,先小预算试脸/帽/衣走样否) |
| 字幕、片名、转场、歌曲合成 | 本地 FFmpeg,不调视频模型 |
| 复杂群舞、多人互动 | 第一版不做,或用有权实拍素材 |
