# 致：花瑶非遗传承人（最谨慎的一类）

**适用对象**：陈治安、奉族群、戴碧生、奉雪妹、沈燕希等
**收件方式**：**严禁直接私信**。必须通过 ① 县文旅局/乡政府 ② 非遗中心 ③ 传承人公开社交账号自报的咨询入口 三种之一。
**核心原则**：传承人不是 KOL，是文化的活载体——**尊重 > 速度**。

---

## 三步走礼仪

### 第一步：通过单位转介

**不要做**：直接拨打传承人手机/微信
**要做**：先发邮件给隆回县文旅局或虎形山乡政府，附上 `01-隆回县文旅局.md` 或 `02-虎形山瑶族乡政府.md` 的内容，明确写：

> "如贵局认可项目，烦请转介至以下传承人，由他们自主决定是否参与。"

### 第二步：传承人主动回应后再发详细资料

只有传承人本人或其家属/学生回复后，才发送以下私信版本。

### 第三步：保留传承人退出权

任何时候传承人表达不愿继续，立即停止，并在 `contacts.md` 标记 `已退出`。

## 拜访礼仪（如传承人愿意见面）

| 必备 | 说明 |
|---|---|
| 自带礼物 | 茶叶 / 当地土产，避免烟酒（部分传承人不沾） |
| 录音录像 | **必须事先口头征求同意**，并在录制前再确认一次 |
| 报酬 | 主动提出"误工费"或"采访费"（300-1000 元/次），由对方决定接受与否 |
| 着装 | 整洁、低调，不穿印 logo 的工装 |
| 同行人 | 最多 2 人，避免成"考察团"姿态 |

## 录音/录像授权书（必备）

如对方同意录制，**当场**签授权书一式两份，明确：

- 用途：开源项目《呜哇·迎客来》
- 协议：CC BY-SA 4.0
- 撤回机制：72 小时内可撤回，永久撤回需 14 天
- 署名方式：[传承人决定]

模板见仓库 `docs/录音授权书模板.md`（待补）。
