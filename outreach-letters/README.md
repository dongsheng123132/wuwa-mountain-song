## 投递顺序建议

```
Week 1-2:  01 → 02              （政府单位先行）
Week 3-4:  03                   （学术圈跟进）
Week 5-6:  04                   （KOL 个性化私信，每天 1-2 封，绝不群发）
Week 7+:   05                   （政府引荐成功后再走）
```

**理由**：政府/学术圈背书会显著提升 KOL 与传承人的回应率。**先难后易**。

## 共同条款（所有信件遵守）

1. **公益、非商业**：所有衍生收益（如有）回流文化推广。
2. **CC BY-SA 4.0**：贡献者署名权受保护。
3. **可撤回**：任何参与方可随时撤回，我们 24-72 小时内整改。
4. **不冒名**：不以「代表官方」「代表族群」名义对外宣传。
5. **不骚扰**：每个对象最多 3 次跟进（7/14/21 天），之后永久停止。
